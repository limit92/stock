# 가치주 스크리닝 · 보유종목 관리

10단계 규칙으로 KOSPI·KOSDAQ 전 종목을 거른 뒤, 매일 아침 **추천 10선 + 추천 사유**와 **보유종목 매도 계획**을 만듭니다.

## 실행

```bash
pip install -r requirements.txt
export DART_API_KEY=발급받은키          # https://opendart.fss.or.kr (무료)
python -m screener.run                  # 결과: output/report_YYYYMMDD.md, output/screen_YYYYMMDD.xlsx
python -m screener.run --only 005930    # 특정 종목만 점검
python -m pytest -q tests               # 합성 데이터로 규칙 검증
```

- 처음 실행할 때는 10년치 재무제표를 받느라 DART API를 수천 건 호출합니다(하루 한도 20,000건). 받은 자료는 `cache/`에 저장되므로 다음 날부터는 시세만 새로 받습니다.
- 필요한 접속 도메인은 `opendart.fss.or.kr`, `data.krx.co.kr`, `raw.githubusercontent.com`, `fchart.stock.naver.com`, `finance.naver.com`, `m.stock.naver.com`입니다.
- 모든 기준값은 `config.toml`에서 바꿀 수 있습니다.

## 10단계 규칙: 구현 방식과 용어 정의

규칙에 정의가 없던 용어는 아래처럼 정했습니다. **(정의안)** 표시는 확인이 필요한 항목입니다.

| # | 규칙 | 구현 |
|---|---|---|
| 1 | 재무자료 검증 | 사업보고서 기준 최근 10년(최소 7년). 영업적자 0회. 오너어닝이 플러스인 해가 80% 이상 |
| 2 | 수익성·건전성 (3개 중 2개) | 지배주주 ROE 10% 이상인 해 80% 이상 / 최근 부채총계÷자본총계 100% 미만 / 10년 평균 영업이익률 7% 이상 |
| 3 | 재무제표 주의 신호 **(정의안)** | 하나라도 걸리면 탈락: ① 감사의견 비적정 ② 최근 3년 누적 영업현금흐름이 순이익의 50% 미만 ③ 최근 2년 연속 영업현금흐름 마이너스 ④ 매출채권·재고자산 증가율이 매출 증가율보다 30%p 이상 높음 ⑤ 순이익의 50% 이상이 영업 외 일회성 이익 ⑥ 최근 3년 유통주식수 10% 이상 증가(유상증자·CB 희석) |
| 4 | 거래 유동성 | 최근 20거래일 평균 거래대금 5억 원 이상 |
| 5 | 기업가치 평가 **(정의안)** | 두 감정사가 모두 현재가보다 높은 적정가를 내야 통과 (기준은 "일반 적정가") |
| 6 | 영업이익 추세 | 3년 전보다 낮고 **동시에** 직전 연도보다도 낮거나 같으면 제외. 3년 전보다 낮아도 직전 연도보다 늘었으면 회복으로 보고 통과 |
| 7 | 적정주가 | 사는 선 = 보수적(이익수익률 10%, PER 10배) / 1차 매도가 = 일반(7%, PER 약 14배) / 2차 매도가 = 후한(4%, PER 25배). 각 단계에서 두 감정사 중 **낮은 값** 사용 |
| 8 | 지분율 반영 | 지배기업 소유주 귀속 순이익을 사용. 오너어닝과 순현금에는 지배지분율(지배주주지분÷자본총계)을 곱함 |
| 9 | 사업 성격 태그 | DART 업종코드(KSIC)로 계절경기형·수주형·원자재가격형·경기민감형·경기방어형 등을 붙이고 업종별 확인사항 표시. 통과 여부에는 영향 없음 |
| 10 | 매수·매도 원칙 | 현재가가 사는 선 이하일 때만 "매수 가능". 1차 매도가에서 절반, 2차에서 나머지를 매도. 주가 하락만으로는 매도하지 않고, 규칙 1~3이 깨지면 "재평가 필요"로 표시 |

### 용어 정의 **(정의안)**

- **오너어닝** = 영업활동현금흐름 − 유형자산 취득 − 무형자산 취득. 버핏의 원래 정의(순이익 + 감가상각 − 유지보수 투자)는 유지보수 투자를 따로 알 수 없어서, 실무에서 쓰는 FCF 근사치를 썼습니다.
- **이익 감정사** = 정상이익 ÷ 요구 이익수익률. 정상이익은 최근 5년 평균 지배주주 순이익과 최근 5년 평균 세후 영업이익(×지배지분율) 중 **작은 값**입니다. 일회성 이익을 걸러내기 위해서입니다.
- **현금 감정사** = 정상 오너어닝(최근 5년 평균 × 지배지분율) ÷ 요구 이익수익률 + 순현금(현금성자산 + 단기금융상품 − 차입금·사채, × 지배지분율).
- **주당 가치**는 DART 「주식의 총수 현황」의 유통주식수(자기주식 제외)로 나눕니다.

### 추천 10선 정렬

1. 사는 선 이하(매수 가능) 종목이 먼저
2. 그다음은 1차 매도가까지 상승여력이 큰 순서

통과 종목이 10개가 안 되면 기준을 낮추지 않고, 통과한 종목만 보여줍니다.

## 보유종목 (holdings.csv)

```
code,name,qty,avg_price,mode,stage,rebound
035720,카카오,2370,56230,mixed,0,35000;37500;40000
```

- `mode=rule`: 10단계 규칙의 1차·2차 매도가를 사용
- `mode=breakeven`: 수수료·세금 포함 본전, +2.5%, +5%에 1/3씩 예약 지정가
- `mode=mixed`: 절반은 breakeven 방식, 나머지 절반은 `rebound` 가격에 분할 정리
- `stage=1`: 1차 매도를 마쳤다는 뜻
- 본전 터치 확률은 추세가 없다고 가정한 근사치이고, 연변동성은 40%로 가정했습니다

## 알려진 한계

- 금융업(은행·보험·증권·지주)은 기본으로 제외합니다(`exclude_financials`).
- 차입금은 계정명("차입금·사채·유동성장기부채")으로 합산하므로, 회사마다 계정 구성이 다르면 오차가 생길 수 있습니다. 리스부채는 넣지 않았습니다.
- 매도 비용은 0.25%로 가정했습니다. 증권사 수수료와 해당 연도 증권거래세율에 맞게 `portfolio.py`의 `SELL_COST`를 바꾸세요.
